# Healthcare Mobile (Flutter)

User-side app. Auth = **Google OAuth** + **India phone OTP** only (no email/password).
Phone rule: India (+91), carriers **Airtel / Jio / Vi** only, **VoIP rejected**.

Carrier/VoIP check is server-side (Twilio Lookup via a Firebase Cloud Function),
because India Mobile Number Portability makes prefix→carrier matching unreliable.

## Screens
- `LoginScreen` — Google + phone, link to signup
- `SignupScreen` — name + Google + phone
- `PhoneInputScreen` → `OtpScreen` — number → carrier gate → OTP
- `WelcomeScreen` — post-login landing + sign out
- `AuthGate` (`lib/app.dart`) routes by auth state

## One-time setup
> Flutter SDK is **not installed** on this machine yet. Install it first, then:

```bash
# 1. Generate native platform folders into this existing project
flutter create .

# 2. Wire Firebase (creates lib/firebase_options.dart)
dart pub global activate flutterfire_cli
flutterfire configure        # enable Phone + Google providers in Firebase console

# 3. Android Google sign-in: add SHA-1/SHA-256 to Firebase, place google-services.json
#    iOS: add reversed client id to Info.plist

# 4. Deploy the carrier-check function
cd functions
npm install
firebase functions:secrets:set TWILIO_SID
firebase functions:secrets:set TWILIO_TOKEN
firebase deploy --only functions
cd ..

# 5. Run
flutter pub get
flutter run
```

## Notes
- `lib/firebase_options.dart` is generated by step 2 — `main.dart` imports it.
- Function region: `asia-south1`. Adjust in `functions/src/index.ts` if needed.
- Twilio Lookup `line_type_intelligence` returns current carrier + line type
  (`mobile`/`voip`/`landline`). Allow-list in `functions/src/index.ts`.
- Firebase Auth "test phone numbers" bypass the Twilio gate (they never hit the
  function), so test the gate against a deployed function with real numbers too.
